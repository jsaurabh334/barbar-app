# QA Documentation — Barbar App

This directory contains all quality assurance documentation for the Barbar App platform.

## Contents

| File | Description |
|------|-------------|
| [`qa-checklist.md`](qa-checklist.md) | Feature-by-feature test checklist with checkboxes |
| [`end-to-end-test.md`](end-to-end-test.md) | Complete lifecycle tests covering all roles |
| [`regression-checklist.md`](regression-checklist.md) | Core tests to run before every release |
| [`bug-report-template.md`](bug-report-template.md) | Structured template for reporting bugs |
| [`release-checklist.md`](release-checklist.md) | Pre-release verification gates |
| [`test-plan.md`](test-plan.md) | Full functional, edge case, and performance test plan |
| [`bug-sheet.md`](bug-sheet.md) | Active bug tracker |

## Process

1. Run tests from `qa-checklist.md` for new features.
2. Run `end-to-end-test.md` for full lifecycle verification.
3. Before every release, run `regression-checklist.md` and `release-checklist.md`.
4. Report bugs using `bug-report-template.md` and add them to `bug-sheet.md`.
